🌳 Gráfica de Rendimiento TreeSort

📊 Análisis de Complejidad

TreeSort depende de la forma del árbol binario de búsqueda (BST).

✔ Caso promedio:

T(n) = n log(n)

❌ Peor caso (árbol desbalanceado):

T(n) = n²

En esta gráfica se muestra el tiempo promedio de ejecución del algoritmo para diferentes tamaños de entrada.

📌 Interpretación:

  • Cuando los datos son aleatorios → comportamiento cercano a n log n
  • Cuando los datos están ordenados → comportamiento cercano a n²
