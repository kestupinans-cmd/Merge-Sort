📘 ¿Cómo funciona MergeSort?

📌 1. Idea principal

MergeSort utiliza la técnica divide y vencerás. Primero divide el problema en partes pequeñas, luego las resuelve y finalmente las combina ordenadamente.

📌 2. División (lo que ves arriba 🔴)

  • El arreglo se divide en dos partes
  • Cada parte se vuelve a dividir
  • Esto continúa hasta tener arreglos de 1 elemento

📌 3. Caso base

Un arreglo de un solo elemento ya está ordenado.

📌 4. Merge (lo que ves abajo 🟢)

  • Se comparan dos arreglos
  • Se toma el menor
  • Se construye un arreglo ordenado paso a paso

📌 5. Ejemplo

[3,7,6,2] → [3,7] [6,2] → [3] [7] [6] [2] → [3,7] [2,6] → [2,3,6,7]

📌 6. Complejidad

T(n) = n · log(n)
  • log(n) niveles
  • n operaciones por nivel
