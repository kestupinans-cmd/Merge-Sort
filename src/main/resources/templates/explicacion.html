📘 Explicación detallada de MergeSort

1. Idea principal

MergeSort es un algoritmo que organiza un arreglo usando la técnica divide y vencerás. Primero divide el problema en partes pequeñas y luego las combina ordenadamente.

2. División (árbol rojo)

  • El arreglo se parte en dos
  • Cada parte se vuelve a dividir
  • Se repite hasta tener elementos individuales

3. Caso base

Cuando un arreglo tiene un solo elemento, ya está ordenado.

4. Mezcla (árbol verde)

  • Se comparan los elementos de dos subarreglos
  • Se toma el menor
  • Se construye un nuevo arreglo ordenado

5. Construcción progresiva

[2] → [2,3] → [2,3,6] → [2,3,6,7]

6. Complejidad

T(n) = n · log(n)

Se divide en log(n) niveles y en cada nivel se recorren n elementos.
