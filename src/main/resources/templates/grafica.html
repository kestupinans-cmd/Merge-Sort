📊 Análisis de Complejidad - MergeSort

📌 1. ¿Qué representa T(n)?

La función T(n) describe el tiempo que tarda un algoritmo en ejecutarse dependiendo del tamaño de entrada n.

📌 2. Complejidad de MergeSort

T(n) = n · log₂(n)

Esta expresión indica que el algoritmo tiene una complejidad O(n log n), lo que significa que crece de forma eficiente incluso con grandes volúmenes de datos.

📌 3. ¿Por qué es n log n?

  • División: El arreglo se divide en mitades → ocurre log₂(n) veces.
  • Combinación: Cada nivel requiere recorrer todos los elementos → n.

Por lo tanto:

Trabajo total = niveles × trabajo por nivel = log(n) × n

📌 4. Interpretación de la gráfica

  • 📈 La curva sólida representa el tiempo real promedio.
  • 📊 La curva punteada representa la función teórica T(n).

Si ambas curvas tienen una forma similar, se confirma que el algoritmo sigue el comportamiento teórico esperado.

📌 5. Conclusión

MergeSort es un algoritmo altamente eficiente para ordenar grandes conjuntos de datos, ya que su complejidad O(n log n) es significativamente mejor que algoritmos como BubbleSort (O(n²)).

Esto lo hace ideal en aplicaciones donde el rendimiento es crítico.
