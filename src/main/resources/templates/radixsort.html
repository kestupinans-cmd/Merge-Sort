📘 ¿Cómo funciona Radix Sort?

📌 1. Concepto general

Radix Sort es un algoritmo de ordenamiento que NO compara elementos directamente. En lugar de eso, organiza los números según sus dígitos, empezando desde el menos significativo.

📌 2. Funcionamiento paso a paso

  • Se identifica el número con más dígitos
  • Se agrupan los números en buckets (0–9) según el dígito actual
  • Se reconstruye el arreglo manteniendo el orden
  • Se repite para el siguiente dígito (decenas, centenas...)

📌 3. Ejemplo

Para el arreglo: [170, 45, 75, 90]

  • Unidades → se agrupan por último dígito
  • Decenas → se vuelve a agrupar
  • Resultado final → arreglo ordenado

📌 4. Complejidad

T(n) = n * k

Donde:

  • n = número de elementos
  • k = número de dígitos del número más grande

📌 5. Ventajas

  • ✔ Muy rápido para grandes volúmenes de datos
  • ✔ No usa comparaciones
  • ✔ Eficiente cuando k es pequeño

📌 6. Desventajas

  • ❌ Usa memoria adicional (buckets)
  • ❌ No es ideal para números con muchos dígitos
