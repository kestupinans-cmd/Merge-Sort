🌳 ¿Cómo funciona TreeSort?

TreeSort es un algoritmo de ordenamiento que utiliza un Árbol Binario de Búsqueda (BST) para organizar los datos. Cada número se inserta dentro del árbol siguiendo reglas de orden, y luego se realiza un recorrido especial para obtener el arreglo ordenado.

📌 1. Idea principal

El algoritmo transforma el arreglo en una estructura jerárquica. Gracias a las propiedades del árbol binario de búsqueda, los elementos quedan organizados automáticamente.

Izquierda < Nodo < Derecha

📌 2. Construcción del árbol

  • El primer número se convierte en la raíz
  • Los números menores van a la izquierda
  • Los números mayores van a la derecha
  • El proceso continúa recursivamente

Cada inserción compara el nuevo valor con los nodos existentes hasta encontrar una posición libre.

📌 3. Ejemplo paso a paso

[7, 3, 9, 1, 5]
  • 7 → raíz del árbol
  • 3 < 7 → hijo izquierdo
  • 9 > 7 → hijo derecho
  • 1 < 3 → izquierda de 3
  • 5 > 3 → derecha de 3

📌 4. Recorrido In-Order

Después de construir el árbol, se realiza un recorrido:

Izquierda → Nodo → Derecha

Este recorrido visita primero los menores, luego el nodo actual y finalmente los mayores, generando automáticamente el arreglo ordenado.

📌 5. Interpretación visual

  • 🌲 Panel izquierdo → construcción del BST
  • 📈 Panel derecho → recorrido In-Order
  • ⬅️ L → hijo izquierdo
  • ➡️ R → hijo derecho

📌 6. Complejidad temporal

Mejor caso: T(n) = n log(n)

Cuando el árbol está balanceado, las inserciones y recorridos son eficientes.

Peor caso: T(n) = n²

El peor caso ocurre cuando los datos llegan ordenados y el árbol se convierte en una lista lineal.

📌 7. Ventajas

  • ✔ Organiza los datos jerárquicamente
  • ✔ Permite búsquedas eficientes
  • ✔ El recorrido genera automáticamente el orden
  • ✔ Muy útil para estructuras dinámicas

📌 8. Desventajas

  • ❌ Puede desbalancearse
  • ❌ Consume memoria adicional
  • ❌ El rendimiento depende de la forma del árbol

📌 9. Aplicaciones reales

  • 📂 Sistemas de archivos
  • 🗂 Índices en bases de datos
  • 🔎 Motores de búsqueda
  • 📊 Gestión dinámica de datos
